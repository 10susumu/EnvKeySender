# EnvKeySender

## 目的

EnvKeySender は Windows 上で常駐し、指定したファンクションキー（例: F13）をグローバルに監視します。トリガーキーが押されたとき、指定された Windows 環境変数の値を取得して、現在フォーカスされているアプリケーションへキーボード入力（SendInput）で送信します。

秘密情報（パスワード等）はソースや設定ファイルに保存しません。

## 必要な環境

- Windows
- .NET 8 SDK

## ビルド方法

1. リポジトリをクローンまたはこのフォルダに移動します。
2. 次を実行します:

```powershell
dotnet build
```

## 起動方法

- ビルド後、生成された実行ファイルを実行するとタスクトレイに常駐します。
- コンソールウィンドウは表示されません。

## 設定方法

1. タスクトレイのアイコンを右クリックして「設定を開く」を選択します。
2. 監視するキー（F1〜F24）と読み込む環境変数名を設定し、「保存して適用」を押してください。
3. 設定は `%APPDATA%/EnvKeySender/settings.json` に JSON 形式で保存されます（環境変数の値は保存しません）。

## 環境変数の設定方法

環境変数は Windows の `環境変数の編集` などから設定してください。優先順位は以下の順です:

1. Process
2. User
3. Machine

例: PowerShell でユーザー環境変数を設定する

```powershell
[Environment]::SetEnvironmentVariable('MYKEY', 'your-secret', 'User')
```

※ 実行後、既に起動しているプロセスは環境変数の変更を自動的に拾わないことがあります。

## ZMK 側の設定例

ZMK などのキーボードファームウェアで任意のキーに `&kp F13` を割り当てることで、このアプリのトリガーにできます。重要: ZMK 側に秘密情報は含めないでください。

## セキュリティ上の注意

- 環境変数の値を画面やログに表示しません。
- 環境変数の値を設定ファイルに保存しません。
- ソースコードや README に実際のパスワードや秘密情報を書かないでください。

## GitHub に公開する際の注意

- 秘密情報がコミットや履歴に残っていないことを必ず確認してください。
- `.gitignore` を使い、ビルド成果物や個人設定を含めないでください。
